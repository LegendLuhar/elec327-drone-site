Mission & Overview

SP26 — IN PROGRESS

Design, build, and fly a fully-custom autonomous quadrotor — from PCB layout and firmware to control loops and live telemetry, in a single semester.

// Context. ELEC 327 is Rice's embedded-systems capstone. Teams are given a chassis, a microcontroller, and a problem. Ours: keep it stable, keep it light, keep it cheap.

// Approach. Iterative bring-up. Start with a benchtop motor mixer, layer in IMU sensor fusion, then close the loop on attitude before ever leaving the tether.

// Status. Currently in tethered hover trials. Telemetry link live, attitude PID tuned, altitude hold next.

OBJ.01
Stable Hover
Hold attitude within ±2° on roll/pitch under no-wind conditions for 60 seconds.
OBJ.02
Closed-Loop Telemetry
Bidirectional 2.4 GHz link streaming IMU + battery state at 50 Hz to ground station.
OBJ.03
Waypoint Navigation
Stretch goal — autonomous traversal of a 4-point indoor course using fused IMU + optical flow.
